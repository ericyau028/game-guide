瑪奇 Mobile 生活技能完全指南｜採集、製作與兼職系統

GameGuide 編輯部 · 2026-07-24 · 約 18 分鐘閱讀 生活技能

生活技能系統總覽

瑪奇 Mobile 的生活技能系統是遊戲中非常重要的一環，分為 採集類 與 製造類 兩大類別，總共 8 種技能。採集類技能負責從野外獲得原材料，製造類技能則將這些材料加工成有用的道具、裝備或消耗品。

生活技能等級越高，可以使用的採集點就越優質，製作出的成品品質也越好。此外，透過 兼職（아르바이트） 系統，玩家可以向 NPC 接取任務賺取額外報酬，是新手累積資源的重要管道。

伐木 벌목 木材 家具與船隻製作

小提示：建議新手優先選 1~2 個生活技能專精，集中資源衝等，效益最高。

採礦（채광）— 獲得礦石，用於鍛造

採礦是獲取金屬礦石的主要方式，這些礦石是 鍛造 技能的基礎材料。玩家可以在野外礦脈進行採集，高等級礦脈需要更高的採礦技能等級才能使用。

可採集的礦石種類

  • 鐵礦石：最基礎的礦石，用於製作初階武器與防具
  • 銅礦石：用於製作中等裝備
  • 銀礦石：稀有礦石，可用於高階裝備
  • 金礦石：高級礦石，製作頂級武器所需
  • 祕銀礦石：傳說級礦石，傳說裝備的核心材料

升級建議

初期以鐵礦為主，隨著等級提升逐步解鎖更高階礦脈。建議搭配 鍛造 技能一起練，形成自產自用的循環。

韓服攻略：採礦 5 級後可前往「巴爾地下城」周邊的高級礦脈，每小時收益約為低級地圖的 3 倍。

伐木（벌목）— 獲得木材，用於家具製作

伐木技能用於砍伐樹木獲得木材，是 家具製作 與 船隻建造 的核心材料來源。不同區域的樹木提供的木材種類也不同。

可獲得的木材種類

  • 普通木材：最常見，用於基本家具
  • 優質木材：用於中高級家具
  • 古代木材：稀有材料，用於傳說級家具與船隻升級
  • 魔法木材：附魔相關製作的輔助材料

實用技巧

伐木時建議攜帶 耐久度高的斧頭，並優先選擇密集的森林區域以提高效率。高等級伐木可解鎖特殊樹種，例如「艾琳森林」深處的古代樹木。

採藥（약초 채집）— 獲得藥草，用於藥水製作

採藥技能用於採集各種藥草，是 藥水製作 的必備技能。藥水在戰鬥中極為重要，高品質的恢復藥水與增益藥水市場需求極大。

主要藥草一覽

藥草名稱 韓文 效果 出現區域
紅色藥草 빨간약초 HP 恢復藥水材料 新手區域

新手推薦：採藥是新手最建議優先練的生活技能！藥水永遠有市場需求，且採集門檻低、升級曲線平緩。

釣魚（낚시）— 獲得魚類、稀有飾品

釣魚是瑪奇 Mobile 中非常受歡迎的休閒生活技能。玩家可以在各種水域進行釣魚，除了獲得魚類作為 料理 材料外，還有機會釣到 稀有飾品 和 食譜。

釣魚可獲得物品

  • 一般魚類：可用於料理製作
  • 稀有魚類：可交易的高價物品
  • 寶箱：隨機開出飾品、金幣或材料
  • 稀有飾品：特定水域有機率釣到傳說級飾品
  • 食譜：學習高級料理的必要道具

釣魚技巧

使用高品質的釣竿可以縮短等待時間；不同水域的魚種不同，建議參考社群分享的釣點攻略。夜間釣魚有更高的機率釣到稀有物品。

料理（요리）— 製作食物，提供增益效果

料理技能可以將各種食材製作成美味的食物，食用後可獲得 各種增益效果（Buff），例如提升攻擊力、防禦力、移動速度或經驗值獲得量等。

料理類別

料理類型 主要效果 範例
攻擊強化 提升物理 / 魔法攻擊力 烤牛排、魔力湯
防禦強化 提升防禦力 / 魔法防禦 燉蔬菜、堅果沙拉
經驗加成 提升經驗值獲得量 水果拼盤、特製蛋糕
恢復強化 提升藥水恢復效果 藥草燉雞、蜂蜜茶
特殊效果 移動速度 / 採集速度提升 能量飲料、輕食組合

料理等級越高，解鎖的食譜越多，製作出的食物效果也越強。組隊出團前記得準備好料理 Buff，能大幅提升團隊戰力。

鍛造（대장장이）— 製作武器防具

鍛造是瑪奇 Mobile 中最重要的製造技能之一，可以將 採礦 獲得的礦石加工成武器與防具。高品質的鍛造裝備甚至比副本掉落更優秀。

鍛造可製作項目

  • 單手劍 / 雙手劍：戰士系主要武器
  • 斧類武器：高傷害、攻速較慢
  • 鈍器：適合防禦型角色
  • 金屬防具：頭盔、鎧甲、手套、靴子
  • 盾牌：提升防禦與格擋率

品質系統

鍛造裝備有品質之分（普通、高級、稀有、傳說），品質取決於材料品質與技能等級。傳說級裝備需要極高技能等級與稀有材料，但數值遠超一般裝備。

經濟效益：高技能等級的鍛造師可以製作暢銷裝備，是遊戲中賺金幣的熱門途徑之一。

紡織（방직）— 製作布料服裝

紡織技能使用各種纖維與毛料製作 布料 和 服裝。許多法系與輕甲職業的裝備都需要紡織技能來製作。

紡織產出

  • 普通布料：基本服裝材料
  • 高級絲綢：法袍與輕甲的核心材料
  • 魔法布料：附魔裝備的基礎材料
  • 時裝：外觀裝扮，無屬性但可交易

紡織與 釣魚 有聯動關係（部分魚類可提煉出特殊纖維），建議同時培養這兩個技能。

附魔（마법 부여）— 裝備屬性附加

附魔技能可以為裝備 附加額外屬性，是後期玩家提升戰力的關鍵系統。附魔需要消耗 附魔卷軸 與材料，高等級附魔的成功率較低但效果驚人。

附魔屬性類型

屬性類型 效果 適用裝備
力量 增加物理攻擊力 武器
智力 增加魔法攻擊力 武器 / 飾品
防禦 增加防禦力 防具
暴擊 增加暴擊率 武器 / 飾品
生命 增加最大 HP 防具 / 飾品

注意事項

  • 附魔有失敗機率，失敗可能導致材料消失
  • 部分高級附魔需要先完成特定任務解鎖
  • 同一件裝備最多可附魔 3 條屬性
  • 附魔卷軸可透過副本、釣魚、交易行獲得

兼職系統（아르바이트）介紹

兼職是 NPC 發布的 賺錢任務，玩家完成後可獲得金幣、經驗值與各種獎勵。兼職是新手快速累積初期資源的最佳途徑之一。

兼職特點

  • 每日限定：每個 NPC 每日可接取有限次數的兼職任務
  • 難度分級：從初級到傳說級，獎勵隨難度提升
  • 關聯技能：部分兼職任務需要特定生活技能等級才能接取
  • 好感度：完成兼職可提升與 NPC 的好感度，解鎖更多獎勵

主要兼職 NPC

NPC 地點 任務類型 需求技能
艾琳雜貨商 堤爾納諾 採集委託 採藥 Lv.1
鐵匠大叔 巴爾 礦石收集 採礦 Lv.3
漁夫海特 港口 魚類運送 釣魚 Lv.2
廚師長 餐館 食材準備 料理 Lv.2
賺錢秘訣：每天完成所有可接取的兼職任務，長期下來累積的金幣非常可觀，還能順便提升生活技能經驗值。

生活技能升級建議

不同生活技能的升級曲線與實用性各有不同，以下是針對不同類型玩家的升級建議：

新手玩家（推薦順序）

  1. 採藥 — 門檻最低，藥水需求量大，容易賺取初期資金
  2. 釣魚 — 休閒掛機即可升級，有機會獲得稀有物品
  3. 料理 — 自產自用 Buff，組隊出團必備
  4. 採礦 — 搭配鍛造形成產業鏈

賺錢導向

  • 鍛造 — 高階裝備永遠有市場
  • 附魔 — 頂級附魔師是公會搶手的人才
  • 料理 — Buff 食物消耗量大，穩定收入來源

自給自足導向

  • 採礦 + 鍛造：自己挖礦自己做裝備
  • 採藥 + 料理：藥草做藥水，食材做料理
  • 釣魚 + 料理：釣魚獲得食材直接烹飪

無論選擇哪條路線，建議每日完成 兼職任務 來獲得額外經驗值與獎勵，長期累積效果顯著。

常見問題 FAQ

Q1：生活技能最多可以練幾個？

所有生活技能都可以練滿，但建議集中資源優先練 2~3 個，等高等後再回頭練其他的。分散投資會拖慢升級速度。

Q2：生活技能等級會影響什麼？

技能等級越高，可使用的採集點越好（獲得更高級的材料），製作出成品的品質也越高。部分高階配方需要特定技能等級才能解鎖。

Q3：兼職任務每天可以解幾次？

每個 NPC 每天提供 3~5 次兼職任務（依好感度而定）。建議每天把所有 NPC 的任務都解完，收益最大化。

Q4：釣魚真的有機會釣到傳說飾品嗎？

有！韓服社群已證實特定水域在夜間有極低機率釣到傳說級飾品。雖然機率很低（約 0.1%），但確實存在，而且釣到的玩家不少。

Q5：附魔失敗裝備會消失嗎？

裝備本體不會消失，但消耗的附魔卷軸與材料會損失。建議使用保護卷軸來降低高階附魔的風險。

Q6：新手應該先練採藥還是釣魚？

建議先練 採藥。採藥升級快、藥水需求穩定、收入即時。釣魚偏向掛機休閒，可以作為第二技能培養。

Q7：生活技能可以交易嗎？

技能本身不能交易，但技能產出的物品（裝備、藥水、食物、附魔卷軸等）都可以在交易行自由交易。這也是生活技能的主要賺錢方式。

總結

瑪奇 Mobile 的生活技能系統內容豐富，8 大技能彼此之間有著密切的 聯動關係。採集類技能為製造類提供原材料，製造類技能則將材料轉化為有價值的成品。

以下是各技能的核心定位整理：

技能 類型 核心定位 推薦程度
採礦 採集 鍛造材料來源 ★★★★☆
伐木 採集 家具 / 船隻材料 ★★★☆☆
採藥 採集 藥水材料（新手首選） ★★★★★
釣魚 採集 休閒掛機 / 稀有飾品 ★★★★☆
料理 製造 Buff 食物（組隊必備） ★★★★★
鍛造 製造 武器防具製作（賺錢首選） ★★★★★
紡織 製造 布料服裝 ★★★☆☆
附魔 製造 裝備強化（後期核心） ★★★★☆

善用 兼職系統 加速升級，並根據自己的遊戲風格選擇適合的技能組合，就能在瑪奇 Mobile 的世界中過上富足的冒險生活！

最終建議：享受生活技能的樂趣，不必急著一次全部練滿。每天做做兼職、掛掛釣魚、採採藥草，不知不覺中就能成為生活大師！
